# TradeLog - Professional Trading Journal

This repository contains TradeLog, a modern trading journal built with React, TypeScript, Vite, Tailwind CSS, and shadcn-ui.

## Quick start (local)

```powershell
git clone <YOUR_GIT_URL>
cd <YOUR_PROJECT_NAME>
npm install
npm run dev
```

## Technologies

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn-ui

## Deploy

Build the app with `npm run build` and deploy the `dist` output to your preferred static host.

If you need help configuring a custom domain or CI/CD, add details here or open an issue.
